# MODEL AI — AdSense Content Pack Installation

## Recommended option
Use `modelai-adsense-ready-complete-website.zip` as the full replacement project if you want the Guides hub integrated into the homepage and the updated public pages all in one deploy.

## If applying only the content add-on
1. Download and extract `modelai-adsense-content-addon.zip`.
2. Upload/extract its folder structure into the **repository root** (not as one ZIP file and not inside an extra wrapper folder).
3. It adds `/guides/` with 13 practical tutorial pages, `assets/guide-content.css`, refreshed About/Contact/Privacy/Terms/Disclaimer pages, `sitemap.html`, `sitemap.xml`, `robots.txt`, `ads.txt` starter, and an index navigation snippet.
4. Add the supplied Guides nav snippet to `index.html`, or use the full complete ZIP, where the navigation and guide-card section are already integrated.
5. Commit to GitHub and wait for a successful Cloudflare Pages production deployment.

## Files included
- `guides/index.html` and 13 topic guides, with examples, common mistakes, related tools, and FAQs.
- `about.html`, `contact.html`, `privacy.html`, `terms.html`, `disclaimer.html`.
- `assets/guide-content.css`.
- `sitemap.html`, `sitemap.xml`, `robots.txt`, `ads.txt`.
- `INDEX-GUIDES-NAV-SNIPPET.html` and `ADSENSE-READINESS.md`.

## Before AdSense review
- Read and tailor all pages to what the live site actually does.
- Confirm the contact address shown on the site is monitored.
- Ensure privacy disclosures match your real Firebase, OpenRouter, Gemini, analytics, cookies/local-storage, and upload practices. Remove statements about services you do not use.
- Test all tool links, CSS, login-free public access, mobile layout, and no empty/error-only pages.
- Do not publish an invented AdSense publisher ID. Replace the comments in `ads.txt` only with the exact record generated in your own AdSense account.
- Google decides approval; no layout or article count guarantees it.
