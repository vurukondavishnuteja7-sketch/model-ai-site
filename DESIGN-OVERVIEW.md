# Design and features

The homepage preserves the reference white/light-blue dashboard: top search and profile controls; blue/purple accents; robot hero banner; stat cards; popular tool cards; category tiles; right AI assistant, tools and tips panels; responsive mobile sidebar. Sticker-style SVGs are used across the 35 tool cards including the new Text Animation Studio.

Features included: Firebase login/signup diagnostic handling, server-side OpenRouter chat and opt-in web search, separate Gemini image generation API, animated AI reply typing with Stop/Regenerate, local chat history and optional Firestore sync, file attachment parsing (images/PDF/text), image/document analysis, browser voice input and read aloud, tool search/category/favorites/recent tools, mobile-responsive controls, basic SEO/sitemap and AdSense-ready placeholders.

Some provider-dependent features remain contingent on Firebase settings, API secrets, model access and quotas; source validation does not establish live functionality with your accounts.
