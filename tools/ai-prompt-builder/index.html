A reliable prompt structure

A useful prompt commonly includes a role, task, context, constraints and output format. State what a successful answer should include, what it should avoid and how uncertainty should be handled. Clear instructions often help more than adding vague words such as “best” or “perfect.”

Save reusable patterns

Keep a copy of prompts that work for repeated tasks and adapt the examples, audience and limits to each new assignment.
