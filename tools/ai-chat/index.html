About this tool

This chat UI calls a server-side API route. Add your provider key as a Cloudflare secret before using it; never put API keys in frontend files or GitHub.

What a secure AI chat needs

The browser sends conversation messages to the same-origin /api/chat route. The Cloudflare Function reads the provider secret server-side and returns text from an OpenAI-compatible endpoint. Cost, latency, model behaviour and data handling depend on the provider you select.

Protect the endpoint

Before enabling a public API key, configure rate limiting, abuse monitoring, usage caps and an appropriate privacy disclosure. Never publish the secret in JavaScript or GitHub.
